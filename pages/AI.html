AI-এর মাধ্যমে Web Development শুরু করার প্রাথমিক Software ও Tools

Web Development শেখা ও প্রজেক্ট তৈরি শুরু করতে নিচের Software ও অনলাইন সেবাগুলো প্রয়োজন হবে।

১
Visual Studio Code (VS Code)

Code লেখার জন্য এটি প্রধান Code Editor। HTML, CSS, JavaScript, TypeScript এবং বিভিন্ন Web Development Project তৈরিতে VS Code ব্যবহার করা হবে।

২
Node.js (LTS Version)

JavaScript ও TypeScript এবং বিভিন্ন Web Development Tool চালানোর জন্য Node.js একটি প্রয়োজনীয় Runtime Environment।

Node.js-এর সঙ্গে npm পাওয়া যায়। npm ব্যবহার করে বিভিন্ন Package ও Development Tool ইনস্টল এবং পরিচালনা করা যায়।

৩
Git Bash

Git Version Control এবং বিভিন্ন Development Command চালানোর জন্য Git Bash একটি Terminal Environment। এর মাধ্যমে Git, Node.js/npm এবং Web Development-এর অন্যান্য Command ব্যবহার করা যাবে।

Windows-এর জন্য Git ডাউনলোড ও ইনস্টল করুন

৪
GitHub Account

Code সংরক্ষণ, Project Management এবং Team-এর সঙ্গে কাজ করার জন্য GitHub ব্যবহার করা হয়। Git Bash-এর মাধ্যমে Local Computer-এর Project GitHub-এ Push, Pull ও Manage করা যাবে।

GitHub-এ Account তৈরি করুন বা Sign in করুন

AI-এর মাধ্যমে Folder-এর HTML ফাইল এডিট করার শর্টকাট নিয়ম

১

৫

এরপর ডান পাশের Chat প্যানেলে Copilot-কে কী পরিবর্তন চান তা লিখে পাঠান।

GitHub-এ ফাইল পাবলিশ করার নিয়ম

GitHub-এ নতুন Repository তৈরি করে Local Computer-এর ফাইল আপলোড ও পাবলিশ করতে নিচের ধাপগুলো অনুসরণ করুন।

১

GitHub-এ Login করার পর উপরে প্লাস (+) চিহ্নের স্থানে ক্লিক করুন (Create new)।

২

New repository ক্লিক করুন।

৩

Repository name লিখুন।

৪

Create repository ক্লিক করুন।

৫

Home থেকে Repositories-এ গিয়ে প্রয়োজনীয় Repository নির্বাচন করুন।

৬

Quick setup — if you’ve done this kind of thing before অংশে uploading an existing file লিংকে ক্লিক করুন। এরপর ফাইল কোথায় আছে তা দেখিয়ে নির্বাচন করুন।

৭

ফাইল আপলোড হওয়ার পর Commit changes ক্লিক করুন।

৮

পরবর্তীতে ফাইল আপডেট বা নতুন ফাইল যোগ করার জন্য Repository-তে Add file ব্যবহার করুন।

GitHub-এর এক একাউন্ট থেকে অন্য একাউন্টে Repository সেভ করার নিয়ম

এক GitHub Account-এর Repository অন্য Account-এ নেওয়ার ৩টি পদ্ধতি নিচে দেওয়া হলো। প্রয়োজন অনুযায়ী যেকোনো একটি বেছে নিন।

পদ্ধতি ১: Fork করে কপি নেওয়া (সবচেয়ে সহজ)

১

যে Account-এ Repository সেভ করতে চান, সেই নতুন Account-এ Login করুন।

২

পুরনো Account-এর Repository-এর লিংকে যান (যেমন github.com/পুরনো-ইউজার/রিপোর-নাম)।

৩

উপরে ডান দিকের Fork বাটনে ক্লিক করুন।

৪

Owner হিসেবে নতুন Account নির্বাচন করুন, প্রয়োজনে Repository name ঠিক করুন এবং Create fork ক্লিক করুন।

৫

কিছুক্ষণের মধ্যেই Repository-র কপি নতুন Account-এ তৈরি হয়ে যাবে। (দ্রষ্টব্য: একই Account-এর নিজের Repository নিজের Account-এ Fork করা যায় না।)

পদ্ধতি ২: Transfer ownership (Repository-র মালিকানা অন্য Account-এ দেওয়া)

১

যে Account-এ Repository আছে, সেখানে Login করে Repository খুলুন।

২

Settings ট্যাবে ক্লিক করুন।

৩

General পেজের একদম নিচে Danger Zone অংশে যান।

৪

Transfer ownership বাটনে ক্লিক করুন।

৫

নতুন Account-এর Username এবং Repository-র নাম লিখে নিশ্চিত করুন।

৬

নতুন Account-এর ইমেইলে আমন্ত্রণ যাবে। সেই Account-এ Login করে আমন্ত্রণটি Accept করলে Repository নতুন Account-এ চলে যাবে। এতে Issues, Stars, Pull Request-সহ সব কিছু সঙ্গে যায়, তবে পুরনো Account থেকে Repository সরে যায়।

পদ্ধতি ৩: Git Bash দিয়ে সম্পূর্ণ History-সহ কপি করা

১

নতুন Account-এ Login করে + > New repository থেকে একটি খালি Repository তৈরি করুন। এখানে README, .gitignore বা License যোগ করবেন না।

২

Git Bash খুলে পুরনো Repository-র সম্পূর্ণ কপি (সব Branch ও History-সহ) নামান:

git clone --mirror https://github.com/পুরনো-ইউজার/রিপোর-নাম.git
৩

নামানো ফোল্ডারে ঢুকুন:

cd রিপোর-নাম.git
৪

নতুন Account-এর খালি Repository-তে সব পাঠিয়ে দিন:

git push --mirror https://github.com/নতুন-ইউজার/রিপোর-নাম.git

Push করার সময় GitHub Login চাইলে নতুন Account-এর তথ্য দিন। Password-এর জায়গায় Personal Access Token লাগতে পারে।

৫

নতুন Account-এর Repository পেজ Refresh করে সব ফাইল ও Commit History এসেছে কিনা দেখুন।

৬

কাজ শেষ হলে লোকাল কপির ফোল্ডারটি মুছে দিতে পারেন:

cd .. rm -rf রিপোর-নাম.git

টিপস: Private Repository হলে অন্য Account-এর Fork বা Clone করার অনুমতি (Collaborator access) থাকা প্রয়োজন। ছোট প্রজেক্টে পদ্ধতি ১, মালিকানা বদলাতে পদ্ধতি ২ এবং History-সহ আলাদা কপি রাখতে পদ্ধতি ৩ ভালো।

HTML-এর <img> ট্যাগ

ওয়েবপেজে ছবি দেখানোর সহজ উপায় 🖼️

মূল কথা

<img> দিয়ে ওয়েবপেজে ছবি দেখানো হয়। এটি খালি ট্যাগ, ক্লোজিং ট্যাগ লাগে না।

<img src="photo.jpg" alt="ছবির বর্ণনা" width="600" height="400">

৪টি জরুরি অ্যাট্রিবিউট

  • src : ছবির ঠিকানা (আবশ্যক)
  • alt : ছবির বর্ণনা, ছবি লোড না হলে এটি দেখায় (আবশ্যক)
  • width, height : মাপ দিলে পেজ লাফায় না
  • loading="lazy" : দরকার হলেই ছবি লোড হয়, পেজ দ্রুত খোলে

ছবি রেসপনসিভ করতে CSS-এ দিন: max-width:100%; height:auto;

HTML-এর <a> (অ্যাঙ্কর) ট্যাগ

লিংক তৈরির ট্যাগ 🔗

মূল কথা

<a> (অ্যাঙ্কর) ট্যাগ দিয়ে লিংক তৈরি হয়। লিংকে ক্লিক করলে অন্য পেজ, ফাইল বা পেজের অন্য অংশে যাওয়া যায়।

<a href="https://example.com" target="_blank" rel="noopener">এখানে ক্লিক করুন</a>

জরুরি অ্যাট্রিবিউট

  • href : লিংকের গন্তব্য (আবশ্যক)
  • target="_blank" : নতুন ট্যাবে খোলে
  • rel="noopener" : নতুন ট্যাবে খুললে নিরাপত্তার জন্য দিন
  • download : ক্লিকে ফাইল ডাউনলোড হয়

href-এ কী কী দেওয়া যায়

  • ওয়েব ঠিকানা: https://example.com
  • পেজের অংশ: #contact
  • ইমেইল: mailto:name@mail.com
  • ফোন: tel:+8801700000000

ছবিকেও লিংক করা যায়: <a href="#"><img src="logo.png" alt="হোম"></a>

<script>
function copyCode(btn){
  var text = btn.parentNode.querySelector('code').textContent;
  var done = function(){
    btn.textContent = 'কপি হয়েছে ✓';
    setTimeout(function(){ btn.textContent = 'কপি'; }, 1500);
  };
  if (navigator.clipboard && navigator.clipboard.writeText) {
    navigator.clipboard.writeText(text).then(done);
  } else {
    var t = document.createElement('textarea');
    t.value = text; document.body.appendChild(t); t.select();
    document.execCommand('copy'); document.body.removeChild(t); done();
  }
}
</script>
